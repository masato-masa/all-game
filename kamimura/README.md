# 名もなき神 ― 村育成放置（ブラウザ実装）

設計ドキュメント v0.2 をブラウザゲームとして実装したものです。
サーバー・API・外部ライブラリを一切使わず、**完全にローカルで動作**します（フォントのみWeb Fonts）。

## 遊び方

`index.html` をブラウザで直接開くだけで動きます（`file://` でも可）。
ローカルサーバーで開く場合：

```bash
python -m http.server 8777
```

セーブは `localStorage` に自動保存され、閉じている間も**最大8時間ぶんのオフライン進行**（×1.1ボーナス）が起動時に計算されます。
右上の `×1 / ×4 / ×16` で早送りできます（動作確認・バランス調整用）。

## ファイル構成

| ファイル | 役割 | 対応する設計章 |
|---|---|---|
| `index.html` | 画面構造とモーダル | ― |
| `assets/style.css` | 全スタイル（スマホ対応込み） | ― |
| `js/data.js` | キャラ・辞書・奇跡・拠点・ステージ・ストーリー等の静的データ | 2／3-3／7-2／8-2／9 |
| `js/state.js` | 状態の生成・保存・復元・共通ユーティリティ | 6 |
| `js/oracle.js` | 疑似AI（キーワードマッチング＋重み付け） | 7 |
| `js/engine.js` | シミュレーション本体（生産・戦闘・人口・イベント・オフライン計算） | 4／5／8／9 |
| `js/ui.js` | 描画・モーダル・トースト | ― |
| `js/main.js` | 起動・コアループ・入力 | 5 |

`characters.json` / `oracleDictionary.json` / `miracles.json` は設計時のデータ定義です。
`file://` では `fetch` が使えないため、**実行時のデータは `js/data.js` が正**です（内容を拡張して展開済み）。
`village-god-game-demo.html` は最初の単体プロトタイプで、この実装に置き換わっています。

## 実装済みの内容

### 2章：初期キャラクター
- ガイン／メイア／ノア／ドルンの4人。それぞれ気質・労働傾向・戦闘適性を保持
- **メイア**＝疲労が高いと村全体の幸福度が下がる（幸福度ハブ）
- **ノア**＝元気なら周囲に微プラス、不安なら微マイナス（無邪気さバフ／`Engine.noahAura`）
- **ドルン**＝在籍中はお告げの解釈ズレ率が 28% → 10% に低下（`Oracle.misreadChance`）
- 初期4人は幸福度が下がっても**決して村を去りません**（愛着オブジェクトの固定化）
- 発展期に入るとメイアが「応急手当」、ドルンが「避難誘導」を習得（4-3）

### 3章：オープニング／チュートリアル
- ナレーション4ページ → 拠点選択
- 拠点は4候補（川／岩窟／丘／廃墟）。**フリーテキストのお告げ**で決まり、キーワードに当たらなければランダム＝「解釈のズレ」を最初に体験させる
- 拠点ごとに食料・資材・防御・遭遇率の倍率が変わります
- 状態駆動のストーリーイベント6種（焚き火／ガインの過去／よそ者の目／ドルンの語り／メイアとノア／黄金期）

### 4章：戦闘・脅威
- 数値比較による自動解決。**約30秒前に予兆通知**
- 戦えない者は「後方支援値」として被害を軽減（最大60%＋倉庫Lv）
- 敗北しても全滅・ゲームオーバーなし。資源喪失と負傷（180秒間 効率40%）のみ
- 敵の強さ＝ステージ×経過時間×人口（85%）＋村の戦力連動（15%）。**備えを怠った村はきちんと負けます**

### 5章：コアループ
- 実時間1秒＝ゲーム内1秒で常時進行、起動時にオフライン差分を一括計算してダイジェスト表示
- ランダム小イベント8種で単調さを回避

### 6章：パラメータ
- 村：信仰値／神ポイント／食料／資材／信仰石／幸福度／治安／人口
- 個体：気質7種／労働傾向5種（合計常に100の配分型）／戦闘適性／忠誠／疲労／士気

### 7章：お告げ（疑似AI）
- NGワード → 「???という不思議なお告げ」に無害化
- 7カテゴリ辞書。**複数カテゴリ混在時は按分**（例：「畑を守りながら祈れ」）
- 未マッチ → 「未知・曖昧」としてランダム小イベント
- 気質による反応倍率（好戦×1.5で戦闘、臆病×0.4＋士気減、勤勉は休息を拒否 等）
- 信仰値が高いほど効果が強い（最大1.6倍）／同カテゴリ連投で効果逓減（150秒ごとに1段回復）
- 3回まで／120秒で1回回復

### 8章：神ポイント（直接介入）
- 信仰値100ごとに1pt、上限は初期5（祭壇2Lvごと＋1、信仰石でも拡張）
- 奇跡7種すべて**確定効果**（ガチャ性なし）

### 9・10章：進行と収益導線
- 開拓期／発展期／繁栄期／黄金期（人口 0／10／30／60）
- 信仰石パネルがリワード広告・IAPのデモ（「祈りを捧げる」＝広告視聴相当で信仰石+1、60秒クールダウン）

## 調整のしどころ

数値はすべて `js/data.js` の定数と `js/engine.js` の係数に集約してあります。

- 生産速度：`Engine.rates()` の `0.50`（食料）／`0.45`（資材）／`0.75`（信仰）
- 敵の強さ：`Engine.enemyEstimate()` と `STAGES[].enemyBase`
- 襲撃間隔：`STAGES[].threatBase`（治安が高いほど延びる）
- 加入間隔：`Engine.updatePopulation()` の `Util.rand(300,480) * (1 + 人口 * 0.25)`
- 辞書の追加：`ORACLE_CATEGORIES` にキーワードを足すだけで反映されます

ブラウザのコンソールから `NAMELESS.state`（現在の状態）、`NAMELESS.skip(3600)`（1時間早送り）が使えます。
